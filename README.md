# Japanese Daily

## Purpose:
To test your Japanese knowledge from JLPT n5 to n1, and beyond. Where the user can select your current JLPT level. Goal is to help learners recall words from the JLPT list of words.

# How to play:
1. Similar to wordle but limited 1 to 25 characters in length making it beginner 

2. You get 4 chances to guess the word pronuncation

3. You get a couple spelling hints
    1. spelling hint
    2. maybe kanji hint meaning
